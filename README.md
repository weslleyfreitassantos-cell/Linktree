# Linktree local

Abra `index.html` no navegador ou rode um servidor local na pasta.

## Personalização rápida

Edite somente `config.js` para trocar:

- nome, bio e marca/avatar;
- cores de fundo, botões e texto;
- fonte (use uma fonte já carregada no `index.html` ou adicione outra do Google Fonts);
- links principais e redes sociais.

Para testar com servidor local, na pasta do projeto:

```powershell
py -m http.server 4173
```

Depois acesse http://localhost:4173.
